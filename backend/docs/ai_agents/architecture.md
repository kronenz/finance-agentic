# AI 에이전트 아키텍처 문서

**Version**: 1.0.0  
**Date**: 2024-12-19  
**System**: AI 기반 적응형 암호화폐 거래 시스템

## 개요

AI 에이전트 시스템은 시장 국면을 자동으로 감지하고 적응형 전략을 통해 자율적으로 거래를 실행하는 다중 에이전트 아키텍처입니다.

## 핵심 에이전트

### 1. Meta-Controller (메타 컨트롤러)

**역할**: 전체 시스템의 중앙 조정자
**주요 기능**:
- 시장 국면 분석 결과 종합
- 전략 선택 및 전환 결정
- 리스크 관리 정책 적용
- 에이전트 간 통신 조정

**입력**:
- 시장 국면 분석 결과
- VWAP/Volume Profile 분석
- 리스크 평가 결과
- 전략 성과 데이터

**출력**:
- 거래 신호 (BUY/SELL/HOLD)
- 전략 전환 명령
- 리스크 관리 조치

### 2. Market Regime Detector (시장 국면 감지기)

**역할**: 시장 국면 자동 감지
**주요 기능**:
- 추세/평균회귀 국면 분류
- 신뢰도 점수 계산
- 국면 전환 예측
- 다중 시간대 분석

**기술적 지표**:
- ADX (Average Directional Index)
- Hurst Exponent
- 볼린저 밴드 압축률
- RSI 다이버전스

### 3. VWAP Analyzer (VWAP 분석기)

**역할**: 거래량 가중 평균 가격 분석
**주요 기능**:
- 실시간 VWAP 계산
- VWAP 편차 분석
- 지지/저항 레벨 식별
- 시장 참여자 행동 분석

**분석 요소**:
- VWAP 대비 가격 편차
- 거래량 분포 패턴
- 시간대별 VWAP 변화
- 거래소별 VWAP 차이

### 4. Volume Profile Analyzer (거래량 프로파일 분석기)

**역할**: 거래량 프로파일 분석
**주요 기능**:
- POC (Point of Control) 식별
- Value Area 계산
- Low Volume Node 탐지
- 시장 합의 가격대 분석

**핵심 메트릭**:
- POC 가격
- Value Area High/Low
- Volume at Price
- Profile Shape Analysis

### 5. Risk Manager (리스크 관리자)

**역할**: 다층적 리스크 관리
**주요 기능**:
- 개별 포지션 리스크 평가
- 포트폴리오 리스크 분석
- 시스템 리스크 모니터링
- 연쇄 청산 위험 감지

**리스크 지표**:
- VaR (Value at Risk)
- 최대 손실 예상치
- 상관관계 분석
- 스트레스 테스트

### 6. RL Optimizer (강화학습 최적화기)

**역할**: 전략 파라미터 최적화
**주요 기능**:
- 전략 성과 학습
- 파라미터 자동 조정
- 보상 함수 최적화
- 정책 개선

**학습 요소**:
- 상태 (시장 조건)
- 행동 (거래 결정)
- 보상 (수익/손실)
- 정책 (의사결정 규칙)

### 7. Genetic Algorithm (유전 알고리즘)

**역할**: 전략 진화 및 개선
**주요 기능**:
- 새로운 전략 생성
- 전략 성과 평가
- 유전적 연산 (교차, 변이)
- 진화적 개선

**진화 과정**:
- 초기 개체군 생성
- 적합도 평가
- 선택, 교차, 변이
- 다음 세대 생성

## 통신 프로토콜

### 메시지 형식

```json
{
  "message_id": "uuid",
  "timestamp": "2024-12-19T10:00:00Z",
  "sender": "agent_name",
  "receiver": "agent_name",
  "message_type": "analysis_result|command|status",
  "payload": {
    "data": "actual_data"
  },
  "priority": "high|medium|low"
}
```

### 메시지 타입

1. **Analysis Result**: 분석 결과 전달
2. **Command**: 명령 전달
3. **Status**: 상태 업데이트
4. **Alert**: 경고/알림
5. **Heartbeat**: 생존 신호
