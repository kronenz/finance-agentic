# 실무 체크리스트 및 템플릿

## 1. 일일 운영 체크리스트

### 1.1 시스템 상태 점검 (매일 오전 9시)
- [ ] **대시보드 접속** 및 전체 시스템 상태 확인
- [ ] **AI 에이전트 상태** 확인 (활성/비활성/오류)
- [ ] **시스템 메트릭** 검토 (CPU, 메모리, 디스크 사용률)
- [ ] **알림 및 경고** 확인 및 처리
- [ ] **어제 작업 완료율** 검토
- [ ] **오늘 작업 계획** 확인

### 1.2 AI 에이전트 작업 리뷰 (매일 오후 2시)
- [ ] **전략 개발자** 작업 결과 검토
  - [ ] 거래 성과 분석 리포트 확인
  - [ ] 새로운 전략 개발 진행 상황 점검
  - [ ] 백테스팅 결과 검토
- [ ] **데이터 엔지니어** 작업 결과 검토
  - [ ] 데이터 파이프라인 상태 확인
  - [ ] 데이터 품질 지표 검토
  - [ ] 새로운 데이터 소스 통합 진행 상황
- [ ] **AI/ML 엔지니어** 작업 결과 검토
  - [ ] 모델 성능 지표 확인
  - [ ] 실험 결과 검토
  - [ ] 모델 업데이트 진행 상황
- [ ] **DevOps 엔지니어** 작업 결과 검토
  - [ ] 인프라 상태 확인
  - [ ] 배포 진행 상황 점검
  - [ ] 보안 스캔 결과 검토
- [ ] **QA 엔지니어** 작업 결과 검토
  - [ ] 테스트 결과 확인
  - [ ] 품질 지표 검토
  - [ ] 발견된 버그 현황 점검

### 1.3 의사결정 및 승인 (매일 오후 4시)
- [ ] **긴급 이슈** 처리 및 의사결정
- [ ] **AI 에이전트 요청사항** 검토 및 승인
- [ ] **리소스 할당** 조정
- [ ] **우선순위 변경** 검토
- [ ] **위험 요소** 식별 및 대응 방안 수립

### 1.4 일일 마무리 (매일 오후 6시)
- [ ] **일일 성과 요약** 작성
- [ ] **내일 우선순위** 설정
- [ ] **이슈 및 액션 아이템** 정리
- [ ] **팀 공유사항** 정리
- [ ] **개인 학습** 시간 확보
