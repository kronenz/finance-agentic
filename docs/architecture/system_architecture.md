## 전체 시스템 아키텍처

### 아키텍처 원칙
1. **마이크로서비스 아키텍처**: 서비스별 독립적 배포 및 확장

3. **이벤트 기반 처리**: 비동기 이벤트 처리로 성능 최적화
4. **클라우드 네이티브**: AWS 클라우드 서비스 활용
5. **보안 우선**: 다층 보안 아키텍처 적용

## 마이크로서비스 아키텍처

### 1. 인증 서비스 (Auth Service)
**기능**: 사용자 인증, 권한 관리, 세션 관리
**기술 스택**: FastAPI, JWT, bcrypt
**데이터베이스**: PostgreSQL (사용자 정보)

**주요 엔드포인트**:
- `POST /auth/register` - 사용자 회원가입
- `POST /auth/login` - 사용자 로그인
- `POST /auth/logout` - 사용자 로그아웃
- `GET /auth/me` - 현재 사용자 정보
- `POST /auth/forgot-password` - 비밀번호 재설정

### 2. 구독 서비스 (Subscription Service)
**기능**: 구독 관리, 결제 처리, 플랜 관리
**기술 스택**: FastAPI, Stripe SDK
**데이터베이스**: PostgreSQL (구독, 결제 정보)

**주요 엔드포인트**:
- `GET /subscriptions/plans` - 구독 플랜 목록
- `POST /subscriptions/subscribe` - 구독 생성
- `PUT /subscriptions/{id}` - 구독 수정
- `DELETE /subscriptions/{id}` - 구독 취소
- `GET /subscriptions/me` - 내 구독 정보

### 3. 거래 서비스 (Trading Service)
**기능**: 거래 전략 실행, 포트폴리오 관리
**기술 스택**: FastAPI, python-binance, TA-Lib
**데이터베이스**: PostgreSQL (거래 기록), Redis (실시간 데이터)

**주요 엔드포인트**:
- `GET /trading/strategies` - 거래 전략 목록
- `POST /trading/strategies` - 전략 생성
- `PUT /trading/strategies/{id}` - 전략 수정
- `GET /trading/portfolio` - 포트폴리오 현황
- `GET /trading/positions` - 포지션 목록

### 4. AI/ML 서비스 (AI Service)
**기능**: 개인화 추천, 시장 분석, 리스크 관리
**기술 스택**: FastAPI, scikit-learn, pandas
**데이터베이스**: PostgreSQL (ML 모델), S3 (모델 파일)

**주요 엔드포인트**:
- `GET /ai/recommendations` - 개인화 추천
- `GET /ai/market-analysis` - 시장 분석
- `GET /ai/risk-assessment` - 리스크 평가
- `POST /ai/feedback` - 사용자 피드백

### 5. 관리자 서비스 (Admin Service)
**기능**: 시스템 관리, 사용자 관리, 모니터링
**기술 스택**: FastAPI, Admin UI
**데이터베이스**: PostgreSQL (시스템 로그)

## 데이터 아키텍처

### 데이터베이스 설계
**주 데이터베이스**: PostgreSQL
- 사용자 정보 (users, user_profiles)
- 구독 정보 (subscriptions, subscription_plans)
- 거래 정보 (trades, positions, strategies)
- 시스템 로그 (audit_logs, error_logs)

**캐시 데이터베이스**: Redis
- 세션 정보
- 실시간 시장 데이터
- API 응답 캐시
- 임시 데이터

### 데이터 플로우
1. **실시간 데이터**: Binance API → Redis → Trading Service
2. **사용자 데이터**: Frontend → Auth Service → PostgreSQL
3. **거래 데이터**: Trading Service → PostgreSQL → AI Service
4. **분석 데이터**: AI Service → S3 → Admin Dashboard

## 보안 아키텍처

### 인증 및 인가
- **JWT 토큰**: 사용자 인증
- **OAuth2**: 소셜 로그인
- **2FA**: 2단계 인증
- **RBAC**: 역할 기반 접근 제어

### 데이터 보안
- **암호화**: AES-256 데이터 암호화
- **전송 보안**: TLS 1.3
- **저장 보안**: 데이터베이스 암호화
- **API 보안**: Rate Limiting, CORS

### 인프라 보안
- **VPC**: 격리된 네트워크
- **WAF**: 웹 애플리케이션 방화벽
- **DDoS 보호**: CloudFlare
- **모니터링**: 보안 이벤트 감지
