# 적응형 전략 프레임워크 설계

## 1. 개요

본 문서는 `concept.md`의 '적응형 이중 국면 모델'과 'Agentic AI의 역할'을 기반으로, 정적 전략의 한계를 극복하고 시장 환경 변화에 동적으로 적응하며 장기적으로 진화하는 적응형 전략 프레임워크를 설계한다. 이 프레임워크는 1) 동적 전략 전환, 2) 전략 파라미터 최적화, 3) 신규 전략 발견의 세 가지 핵심 메커니즘으로 구성된다.

## 2. 프레임워크 구성 요소

### 2.1. 전략 라이브러리 (Strategy Library)

시스템이 사용할 수 있는 모든 거래 전략의 코드가 저장된 라이브러리. 각 전략은 표준화된 인터페이스를 구현해야 한다.

-   **추세추종 전략**:
    -   `SuperTrendStrategy`: 슈퍼트렌드 지표 기반
    -   `DmaCrossStrategy`: 이중 이동평균선 교차 기반
-   **평균회귀 전략**:
    -   `RsiReversionStrategy`: RSI 과매도/과매수 기반
    -   `FearAndGreedStrategy`: 공포/탐욕 지수 역발상 기반
    -   `BollingerBandStrategy`: 볼린저 밴드 상하단 터치 기반

### 2.2. 동적 전략 전환 메커니즘 (Dynamic Strategy Switching)

-   **목표**: 현재 시장 국면에 가장 적합한 전략을 실시간으로 선택하고 활성화한다.
-   **설계**:
    1.  **트리거**: `시장 국면 분석 에이전트`로부터 새로운 국면 분류 결과(예: `RANGE_HIGH_VOL`)를 수신한다.
    2.  **매핑**: `메타-컨트롤러`는 사전에 정의된 '국면-전략 매핑 테이블'을 참조한다.
        -   `TREND_UP/DOWN`: `SuperTrendStrategy` 또는 `DmaCrossStrategy` 활성화
        -   `RANGE_HIGH_VOL`: `RsiReversionStrategy` 활성화
        -   `RANGE_LOW_VOL`: `BollingerBandStrategy` 활성화
        -   `CRASH_EVENT` / `EXTREME_FEAR`: `FearAndGreedStrategy` 활성화
    3.  **실행**: `메타-컨트롤러`는 `전략 분석 에이전트`에 해당 전략을 활성화하도록 지시하고, 기존에 활성화된 다른 패러다임의 전략은 비활성화한다.

### 2.3. 강화학습(RL) 기반 전략 최적화

-   **목표**: 시장 상황 변화에 맞춰 기존 전략의 핵심 파라미터를 동적으로 미세 조정(Fine-tuning)하여 전략의 효율을 극대화한다.
-   **설계**:
    -   **RL 에이전트**: `메타-컨트롤러` 내부에 강화학습 에이전트를 둔다.
    -   **상태 (State)**: 현재 시장 국면, 변동성(ATR), 거래량, 미결제 약정 등 시장을 나타내는 주요 지표들.
    -   **행동 (Action)**: 활성화된 전략의 주요 파라미터를 조정하는 행위.
        -   *예시 (RsiReversionStrategy)*: RSI 과매도 기준을 20에서 25로 상향, 과매수 기준을 80에서 75로 하향.
        -   *예시 (SuperTrendStrategy)*: ATR 기간을 10에서 12로 늘려 변동성에 대한 민감도를 낮춤.
    -   **보상 (Reward)**: 파라미터 조정 이후 발생한 거래의 수익률(PnL), 샤프 지수(Sharpe Ratio) 등을 보상으로 정의한다. 긍정적 결과에는 양의 보상을, 부정적 결과에는 음의 보상을 부여한다.
    -   **학습**: RL 에이전트는 시간이 지남에 따라 어떤 '상태'에서 어떤 '행동'을 하는 것이 누적 '보상'을 극대화하는지 학습한다. 이를 통해, 예를 들어 '고변동성 횡보' 국면에서는 RSI 기준을 더 보수적으로 잡는 것이 유리하다는 정책(Policy)을 스스로 형성하게 된다.

### 2.4. 유전 알고리즘(GA)을 통한 전략 진화

-   **목표**: 기존 전략의 조합이나 변형을 통해, 또는 완전히 새로운 규칙을 발견하여 장기적으로 더 우수한 성능을 내는 새로운 전략을 '진화'시킨다.
-   **설계**:
    1.  **개체(Individual) 정의**: 하나의 거래 전략을 하나의 '유전자(Gene)'로 표현한다. 유전자는 조건(Condition)과 행동(Action)의 조합으로 구성된다.
        -   *예시*: `IF (RSI(14) < 30 AND ADX(14) < 20) THEN BUY`
    2.  **초기 집단(Initial Population) 생성**: `전략 라이브러리`의 기존 전략들과 그 변형들을 초기 집단으로 사용한다.
    3.  **적합도 평가(Fitness Evaluation)**: 각 전략(개체)을 과거 데이터로 백테스팅하여 성과(예: 샤프 지수, 총수익률)를 측정한다. 이 성과가 해당 개체의 '적합도'가 된다.
    4.  **선택(Selection)**: 적합도가 높은 상위 개체들을 다음 세대로 생존시킨다.
    5.  **교차(Crossover)**: 생존한 두 개체(부모)의 유전자(규칙)를 조합하여 새로운 개체(자식)를 생성한다.
        -   *예시*:
            -   부모 1: `IF (RSI < 30) THEN BUY`
            -   부모 2: `IF (Close > SMA(50)) THEN BUY`
            -   자식: `IF (RSI < 30 AND Close > SMA(50)) THEN BUY`
    6.  **변이(Mutation)**: 생성된 자식의 유전자를 무작위로 일부 변경한다 (예: `RSI < 30`을 `RSI < 25`로 변경). 이는 집단의 다양성을 유지하고 새로운 탐색을 가능하게 한다.
    7.  **반복**: 위 과정을 주기적으로 (예: 매주, 매월) 반복 실행한다. 수 세대를 거쳐 진화한 결과, 기존에 없던 새롭고 강력한 전략이 발견되면, 백테스팅 및 검증을 거쳐 `전략 라이브러리`에 추가하고 실제 거래에 투입할 후보로 등록한다.

## 3. 프레임워크 운영 사이클

-   **실시간 (Real-time)**: `동적 전략 전환 메커니즘`이 시장 국면에 즉각적으로 반응.
-   **단기 (Short-term)**: `강화학습 기반 최적화`가 수 시간 ~ 수 일 단위로 전략 파라미터를 미세 조정.
-   **장기 (Long-term)**: `유전 알고리즘 기반 진화`가 수 주 ~ 수 개월 단위로 새로운 전략을 탐색하고 라이브러리를 업데이트.
