# 실시간 시장 데이터 통합 파이프라인 설계

## 1. 개요

본 문서는 `concept.md`에서 강조된 'Agentic AI'가 시장을 다차원적으로 '컨텍스트화'하는 데 필요한 모든 데이터를 실시간으로 수집, 처리, 제공하기 위한 데이터 파이프라인의 상세 설계를 다룬다. 이 파이프라인은 AI 에이전트의 '감각' 역할을 수행하며, 의사결정의 품질을 좌우하는 핵심 기반 시설이다.

## 2. 데이터 소스 및 수집 방법

AI 에이전트의 의사결정에 필요한 데이터는 `concept.md`에 따라 미시적, 거시적, 온체인, 소셜 데이터로 분류되며, 각 데이터의 특성에 맞는 수집 방법을 사용한다.

### 2.1. 거래소 데이터 (미시적)

- **데이터 종류**: 실시간 체결 데이터(Ticks), 오더북, 캔들(OHLCV), 펀딩비, 미결제 약정
- **수집 방법**:
    - **WebSocket API**: 다중 거래소(Binance, Bybit, OKX 등)의 WebSocket 스트림에 연결하여 지연 시간을 최소화한 실시간 데이터를 수신한다.
    - **REST API**: WebSocket에서 제공하지 않는 보조 데이터(예: 일일 미결제 약정)를 주기적으로 폴링(Polling)하여 수집한다.

### 2.2. 온체인 데이터

- **데이터 종류**: 고래(대규모 보유자) 지갑의 이동, 거래소로의 BTC/ETH 입출금 흐름, 활성 주소 수, 채굴자 포지션 지수(MPI), 네트워크 해시레이트
- **수집 방법**:
    - **전용 노드 운영**: 자체 비트코인/이더리움 노드를 운영하여 블록체인 데이터를 직접 분석하고, 가장 신뢰성 높은 원본 데이터를 확보한다.
    - **서드파티 API 활용**: Glassnode, CryptoQuant와 같은 전문 온체인 데이터 제공 업체의 API를 활용하여 정제되고 분석된 고급 지표를 수집한다.

### 2.3. 소셜 및 감성 데이터

- **데이터 종류**: 트위터, 레딧 등 주요 소셜 미디어의 암호화폐 관련 게시물, 댓글, 언급량. 공포 및 탐욕 지수.
- **수집 방법**:
    - **스트리밍 API**: Twitter API 등을 사용하여 특정 키워드(예: $BTC, #Bitcoin, #Crypto)가 포함된 게시물을 실시간으로 스트리밍한다.
    - **웹 스크레이핑/API**: Alternative.me와 같은 사이트에서 공포 및 탐욕 지수를 주기적으로 수집한다.

### 2.4. 거시 경제 데이터

- **데이터 종류**: 미국 연준 금리 결정, 소비자물가지수(CPI), 생산자물가지수(PPI) 등 주요 경제 지표 발표 일정 및 결과.
- **수집 방법**:
    - **전문 데이터 제공업체 API**: Bloomberg, Reuters 또는 금융 정보 API를 구독하여 신뢰성 있는 데이터를 수신한다.
    - **캘린더 파싱**: Investing.com과 같은 금융 캘린더 웹사이트를 주기적으로 파싱하여 발표 일정을 사전에 인지한다.

## 3. 파이프라인 아키텍처 (Kafka 기반)

1.  **Producers**: 각 데이터 소스(거래소 WebSocket, 온체인 노드, 트위터 API 등)에 연결된 독립적인 수집 에이전트(Producer)를 운영한다. 이들은 수집한 원본 데이터를 정규화된 포맷으로 변환하여 Kafka 토픽(Topic)으로 전송한다.
    - **Kafka Topics**: `market-trades`, `onchain-transactions`, `social-mentions`, `macro-events` 등 데이터 종류별로 토픽을 분리한다.

2.  **Kafka Cluster**: 대용량 데이터 스트림을 안정적으로 처리하고 버퍼링하기 위한 메시지 큐 시스템의 핵심. 데이터 급증 시에도 시스템 전체의 안정성을 보장한다.

3.  **Stream Processors (Consumers)**: Kafka 토픽을 구독(Subscribe)하여 실시간 데이터를 처리하고, AI 에이전트가 사용할 수 있는 의미 있는 정보로 가공한다.
    - **기술적 지표 계산**: `market-trades` 토픽의 데이터를 받아 실시간으로 RSI, 이동평균, VWAP 등을 계산한다.
    - **감성 분석**: `social-mentions` 토픽의 텍스트 데이터에 대해 자연어 처리(NLP) 모델을 적용하여 감성 점수(긍정/부정/중립)를 추출한다.
    - **이상 탐지**: `onchain-transactions` 토픽에서 비정상적인 대규모 입출금(고래 이동)을 탐지하여 알림을 생성한다.

4.  **Data Sinks (저장소)**: 처리된 데이터를 목적에 맞게 다양한 데이터베이스에 저장한다.
    - **시계열 데이터베이스 (Time-Series DB, 예: InfluxDB)**: 모든 실시간 시계열 데이터(가격, 지표, 감성 점수 등)를 저장하여 빠른 조회 및 시각화를 지원한다.
    - **데이터 레이크 (Data Lake, 예: S3)**: 모든 원본 데이터를 장기 보관하여 모델 학습 및 심층 분석에 활용한다.

5.  **API 서버**: AI 에이전트 및 리스크 관리 시스템이 필요한 데이터를 실시간으로 조회할 수 있도록 RESTful API 및 WebSocket 엔드포인트를 제공한다.

## 4. 데이터 품질 및 관리

- **모니터링 및 알림**: 데이터 파이프라인의 각 단계(수집, 처리, 저장)를 모니터링하고, 데이터 누락이나 지연 발생 시 즉시 알림을 보내는 시스템을 구축한다.
- **데이터 검증**: 수집된 데이터의 무결성(예: 캔들 데이터의 시가/고가/저가/종가 관계)을 검증하는 로직을 포함한다.

## 5. 결론

본 실시간 데이터 파이프라인은 AI 에이전트가 시장의 미세한 맥박부터 거시적인 흐름까지 놓치지 않고 감지할 수 있게 하는 중추 신경계이다. 이 파이프라인을 통해 제공되는 풍부하고 정확한 실시간 컨텍스트는 AI 에이전트가 더 높은 차원의 분석과 적응적 의사결정을 내리는 데 필수적인 기반이 될 것이다.
