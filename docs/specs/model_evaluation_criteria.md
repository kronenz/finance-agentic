# Model Evaluation Criteria

## 1. 개요

본 문서는 개발된 ML 모델의 성능을 평가하기 위한 기준을 정의한다. 평가는 모델의 예측 정확성뿐만 아니라, 금융 거래 관점에서의 실용성과 수익성을 종합적으로 고려해야 한다.

## 2. 분류 모델 평가 지표 (Classification Metrics)

매수/매도/보유와 같은 클래스를 예측하는 모델에 사용된다.

- **Accuracy (정확도)**: 전체 예측 중 올바르게 예측한 비율. 시장이 불균형할 경우(예: 대부분 '보유' 상태) 해석에 주의.
- **Precision (정밀도)**: '매수'로 예측한 것 중 실제로 상승한 비율. 거짓된 매수 신호를 줄이는 것이 중요할 때 사용.
- **Recall (재현율)**: 실제 상승한 것 중 모델이 '매수'로 예측한 비율. 모든 매수 기회를 포착하는 것이 중요할 때 사용.
- **F1-Score**: 정밀도와 재현율의 조화 평균. 두 지표가 모두 중요할 때 사용.
- **AUC-ROC Curve**: 모델이 양성 클래스와 음성 클래스를 얼마나 잘 구별하는지 나타내는 지표.
- **Confusion Matrix (혼동 행렬)**: 예측 결과를 TP, FP, FN, TN으로 분류하여 모델의 예측 패턴을 상세히 분석.

## 3. 회귀 모델 평가 지표 (Regression Metrics)

미래 가격이나 수익률을 직접 예측하는 모델에 사용된다.

- **MAE (Mean Absolute Error)**: 예측 오차의 절대값 평균. 오차의 크기를 직관적으로 파악하는 데 용이.
- **MSE (Mean Squared Error)**: 예측 오차의 제곱 평균. 큰 오차에 더 큰 패널티를 부여.
- **RMSE (Root Mean Squared Error)**: MSE에 제곱근을 취한 값. MAE와 같이 실제 값과 유사한 단위를 가짐.
- **R-squared (결정 계수)**: 모델이 데이터의 분산을 얼마나 잘 설명하는지 나타내는 지표. 1에 가까울수록 설명력이 높음.

## 4. 금융 성과 평가 지표 (Financial Performance Metrics)

백테스팅 및 실거래 시뮬레이션 결과를 평가하는 데 사용되는 핵심 지표이다.

- **Total PnL (Profit and Loss)**: 총 손익. 전략의 최종 수익성을 나타냄.
- **Sharpe Ratio (샤프 지수)**: 위험 대비 수익률. (수익률 - 무위험 수익률) / 수익률 표준편차. 가장 보편적인 위험 조정 성과 지표.
- **Sortino Ratio (소르티노 지수)**: 하방 위험 대비 수익률. 수익률이 목표 이하로 떨어진 경우(하방 편차)만 위험으로 간주.
- **Maximum Drawdown (MDD)**: 최대 낙폭. 특정 기간 동안 발생한 최대 자산 하락률. 전략의 잠재적 최대 손실 위험을 나타냄.
- **Win/Loss Ratio**: 수익을 낸 거래의 비율.
- **Profit Factor**: 총 수익을 총 손실로 나눈 값. 1보다 커야 하며, 높을수록 좋음.

## 5. 시계열 특화 평가 지표

시계열 데이터의 특성을 고려한 추가 평가 지표들이다.

- **Directional Accuracy**: 가격 방향(상승/하락) 예측 정확도
- **Hit Rate**: 수익을 낸 거래의 비율
- **Average Win/Loss**: 평균 수익 거래와 평균 손실 거래의 크기 비교
- **Consecutive Wins/Losses**: 연속 수익/손실 거래의 최대 길이

## 6. 위험 관리 평가 지표

거래 전략의 위험 관리 능력을 평가하는 지표들이다.

- **Value at Risk (VaR)**: 특정 확률(예: 95%)에서 예상되는 최대 손실
- **Expected Shortfall (ES)**: VaR를 초과하는 손실의 기댓값
- **Calmar Ratio**: 연간 수익률을 최대 드로우다운으로 나눈 비율
- **Sterling Ratio**: 평균 수익률을 평균 드로우다운으로 나눈 비율

## 7. 모델 안정성 평가

모델의 일관성과 안정성을 평가하는 지표들이다.

- **Cross-Validation Score**: K-fold 교차 검증을 통한 성능의 일관성
- **Time Series Cross-Validation**: 시계열 데이터에 특화된 교차 검증
- **Rolling Window Performance**: 슬라이딩 윈도우를 통한 성능 변화 추이
- **Out-of-Sample Performance**: 훈련에 사용되지 않은 데이터에 대한 성능

## 8. 실시간 성능 평가

실제 거래 환경에서의 모델 성능을 평가하는 지표들이다.

- **Latency**: 예측 요청부터 결과 반환까지의 시간
- **Throughput**: 단위 시간당 처리 가능한 예측 요청 수
- **Memory Usage**: 모델 실행 시 메모리 사용량
- **CPU/GPU Utilization**: 하드웨어 리소스 사용률

## 9. 평가 기준 및 임계값

### 9.1. 최소 성능 기준

- **Accuracy**: 60% 이상
- **Sharpe Ratio**: 1.0 이상
- **Maximum Drawdown**: 20% 이하
- **Win Rate**: 55% 이상

### 9.2. 우수 성능 기준

- **Accuracy**: 70% 이상
- **Sharpe Ratio**: 1.5 이상
- **Maximum Drawdown**: 15% 이하
- **Win Rate**: 65% 이상

### 9.3. 실시간 성능 기준

- **Latency**: 100ms 이하
- **Throughput**: 1000 TPS 이상
- **Memory Usage**: 2GB 이하
- **CPU Utilization**: 80% 이하

## 10. 평가 프로세스

### 10.1. 개발 단계 평가

1. **단위 테스트**: 개별 모델의 기본 성능 측정
2. **통합 테스트**: 전체 파이프라인에서의 성능 측정
3. **백테스팅**: 과거 데이터를 이용한 성능 검증
4. **Paper Trading**: 실시간 모의 거래를 통한 검증

### 10.2. 운영 단계 평가

1. **실시간 모니터링**: 지속적인 성능 지표 추적
2. **정기 성과 검토**: 주간/월간 성과 리포트 생성
3. **모델 재학습**: 성능 저하 시 자동 재학습 트리거
4. **A/B 테스트**: 새로운 모델과 기존 모델의 성과 비교

## 11. 평가 도구 및 자동화

### 11.1. 평가 도구

- **MLflow**: 모델 버전 관리 및 성능 추적
- **Weights & Biases**: 실험 관리 및 시각화
- **Prometheus + Grafana**: 실시간 모니터링 대시보드
- **Custom Dashboard**: 금융 특화 성과 지표 시각화

### 11.2. 자동화 스크립트

- **성능 평가 자동화**: 정기적인 성능 지표 계산
- **알림 시스템**: 성능 저하 시 자동 알림
- **리포트 생성**: 자동화된 성과 리포트 생성
- **모델 배포**: 성능 기준 충족 시 자동 배포
