# AI 에이전트 역할 분담 명세서

## 문서 정보
- **문서명**: AI 에이전트 역할 분담 명세서
- **버전**: 1.0.0
- **작성일**: 2024-12-23
- **작성자**: Cursor Agent (System Architect)
- **검토자**: Gemini CLI
- **승인자**: Human Manager

## 1. 개요

### 1.1 목적
Gemini CLI와 Cursor Agent 간의 효율적인 협업을 위해 각 도구의 강점을 분석하고 명확한 역할 분담을 정의한다.

### 1.2 범위
- 코드 개발 및 리팩토링
- 문서화 및 명세서 작성
- 테스트 및 품질 보증
- 아키텍처 설계 및 최적화
- 문제 해결 및 디버깅

## 2. 도구별 강점 분석

### 2.1 Gemini CLI 강점
- **대화형 협업**: 자연어 기반 상호작용으로 복잡한 요구사항 이해
- **전체적 관점**: 프로젝트 전체 맥락을 고려한 종합적 분석
- **창의적 솔루션**: 다양한 접근 방식과 혁신적 아이디어 제안
- **문서화**: 상세한 설명과 가이드라인 작성
- **코드 리뷰**: 전체적인 코드 품질 및 아키텍처 관점에서의 검토
- **학습 및 연구**: 새로운 기술 트렌드 분석 및 적용 방안 제시

### 2.2 Cursor Agent 강점
- **정밀한 코드 수정**: 파일 단위의 정확한 코드 편집 및 리팩토링
- **실시간 실행**: 터미널 명령어 실행 및 즉시 결과 확인
- **구조적 작업**: 디렉토리 구조 분석 및 체계적 파일 관리
- **디버깅**: 구체적인 오류 분석 및 단계별 해결
- **테스트 실행**: 실제 테스트 코드 작성 및 실행
- **빠른 반복**: 작은 단위의 빠른 수정 및 검증

## 3. 역할 분담 정의

### 3.1 Gemini CLI 담당 영역

#### 3.1.1 전략적 기획 및 설계
- **아키텍처 설계**: 전체 시스템 구조 및 컴포넌트 간 관계 설계
- **기능 명세**: 상세한 기능 요구사항 및 사용자 스토리 작성
- **기술 스택 선택**: 프로젝트에 적합한 기술 스택 및 라이브러리 선정
- **성능 최적화 전략**: 전체적인 성능 개선 방안 수립

#### 3.1.2 문서화 및 가이드
- **API 문서**: 상세한 API 명세서 및 사용 가이드 작성
- **아키텍처 문서**: 시스템 설계 문서 및 다이어그램 작성
- **사용자 가이드**: 최종 사용자를 위한 매뉴얼 및 튜토리얼
- **개발 가이드**: 개발자를 위한 코딩 스타일 및 베스트 프랙티스

#### 3.1.3 코드 리뷰 및 품질 관리
- **전체적 코드 리뷰**: 아키텍처 관점에서의 코드 품질 평가
- **보안 검토**: 보안 취약점 및 개선사항 분석
- **성능 분석**: 전체적인 성능 병목 지점 식별
- **코드 스타일 가이드**: 일관된 코딩 스타일 정의 및 적용

#### 3.1.4 복잡한 문제 해결
- **알고리즘 설계**: 복잡한 비즈니스 로직 및 알고리즘 설계
- **데이터 모델링**: 데이터베이스 스키마 및 관계 설계
- **통합 전략**: 다양한 서비스 간 통합 방안 수립
- **확장성 설계**: 미래 요구사항을 고려한 확장 가능한 설계

### 3.2 Cursor Agent 담당 영역

#### 3.2.1 구체적 구현 및 수정
- **코드 구현**: 명세서에 따른 실제 코드 작성
- **버그 수정**: 구체적인 오류 수정 및 개선
- **리팩토링**: 코드 구조 개선 및 최적화
- **파일 관리**: 프로젝트 파일 구조 관리 및 정리

#### 3.2.2 테스트 및 검증
- **단위 테스트**: 개별 함수 및 컴포넌트 테스트 작성
- **통합 테스트**: 서비스 간 통합 테스트 구현
- **성능 테스트**: 구체적인 성능 측정 및 최적화
- **자동화 테스트**: CI/CD 파이프라인 테스트 구현

#### 3.2.3 실행 및 배포
- **환경 설정**: 개발 환경 구성 및 의존성 관리
- **빌드 및 배포**: 실제 빌드 프로세스 및 배포 실행
- **모니터링**: 시스템 상태 모니터링 및 로그 분석
- **유지보수**: 일상적인 시스템 유지보수 작업

#### 3.2.4 즉시 실행 작업
- **명령어 실행**: 터미널 명령어 실행 및 결과 확인
- **파일 편집**: 정확한 파일 수정 및 업데이트
- **디버깅**: 실시간 오류 분석 및 해결
- **검증**: 변경사항 즉시 테스트 및 검증

## 4. 협업 워크플로우

### 4.1 프로젝트 초기화 단계
1. **Gemini CLI**: 프로젝트 전체 아키텍처 설계 및 명세서 작성
2. **Cursor Agent**: 기본 프로젝트 구조 생성 및 환경 설정
3. **Gemini CLI**: 상세 기능 명세서 및 API 설계
4. **Cursor Agent**: 기본 코드 템플릿 및 스켈레톤 구현

### 4.2 개발 단계
1. **Gemini CLI**: 기능별 상세 명세서 작성 및 설계 검토
2. **Cursor Agent**: 명세서에 따른 실제 코드 구현
3. **Gemini CLI**: 구현된 코드 리뷰 및 개선사항 제안
4. **Cursor Agent**: 제안사항 반영 및 코드 수정
5. **Gemini CLI**: 최종 검토 및 문서화

### 4.3 테스트 및 배포 단계
1. **Cursor Agent**: 테스트 코드 작성 및 실행
2. **Gemini CLI**: 테스트 전략 수립 및 품질 기준 정의
3. **Cursor Agent**: 실제 배포 및 환경 구성
4. **Gemini CLI**: 배포 후 모니터링 전략 및 가이드 작성

## 5. 통신 프로토콜

### 5.1 작업 전달 방식
- **Gemini → Cursor**: 명세서, 설계 문서, 리뷰 결과를 파일로 전달
- **Cursor → Gemini**: 구현 결과, 테스트 결과, 이슈 보고를 파일로 전달

### 5.2 협업 도구
- **공유 파일**: `docs/collaboration/` 디렉토리 활용
- **상태 추적**: `docs/specs/` 디렉토리의 진행 상황 문서
- **이슈 관리**: `docs/issues/` 디렉토리의 이슈 추적

### 5.3 품질 게이트
- **설계 검토**: Gemini CLI의 아키텍처 승인 필요
- **구현 검토**: Cursor Agent의 구현 완료 확인 필요
- **테스트 통과**: 모든 테스트 케이스 통과 필수
- **문서화 완료**: 관련 문서 업데이트 완료 필수
