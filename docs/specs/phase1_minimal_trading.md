# Phase 1: 최소 기능 자동화 거래 시스템 명세서

## 1. 개요

Phase 1은 concept.md에서 제시된 이론적 프레임워크의 가장 기본적인 구현체입니다. 복잡한 AI 에이전트나 적응형 시스템 없이, 검증된 기술적 지표를 사용한 단순하지만 효과적인 자동화 거래 시스템을 구축합니다.

## 2. 핵심 목표

- **실용성**: 즉시 사용 가능한 기본적인 자동화 거래 기능
- **안정성**: 검증된 기술적 지표와 엄격한 리스크 관리
- **확장성**: 향후 고도화를 위한 견고한 아키텍처 기반
- **투명성**: 모든 거래 로직이 명확하고 추적 가능

## 3. 기능 명세

### 3.1 핵심 거래 전략

#### 3.1.1 슈퍼트렌드 기반 추세추종 전략
- **지표**: 슈퍼트렌드 (ATR 기반)
- **진입 조건**: 슈퍼트렌드가 적색에서 녹색으로 전환
- **청산 조건**: 슈퍼트렌드가 녹색에서 적색으로 전환
- **손절매**: 슈퍼트렌드 라인 자체가 동적 손절매 역할

#### 3.1.2 RSI 기반 평균회귀 전략
- **지표**: 14기간 RSI
- **진입 조건**: RSI < 30 (과매도) 또는 RSI > 70 (과매수)
- **청산 조건**: RSI가 50 근처로 회귀하거나 10일 경과
- **리스크 관리**: 고정 비율 손절매

### 3.2 리스크 관리 시스템

#### 3.2.1 포지션 크기 관리
- **최대 포지션**: 계좌 자본의 1% 이하
- **레버리지**: 최대 5배 (보수적 설정)
- **격리 마진**: 모든 거래에 격리 마진 사용

#### 3.2.2 손실 제한
- **일일 최대 손실**: 계좌 자본의 2%
- **연속 손실 제한**: 3회 연속 손실 시 거래 중단
- **강제 청산 방지**: 유지 증거금의 150% 수준에서 자동 청산

### 3.3 데이터 관리

#### 3.3.1 가격 데이터
- **소스**: 바이낸스 API (실시간)
- **시간대**: 1분봉, 5분봉, 1시간봉, 일봉
- **보관**: 최근 1년 데이터 로컬 캐시

#### 3.3.2 거래 기록
- **로그**: 모든 거래 결정과 결과 기록
- **데이터베이스**: SQLite 기반 거래 히스토리
- **백업**: 일일 자동 백업

## 4. 기술 스택

### 4.1 핵심 라이브러리
- **Python 3.9+**: 메인 프로그래밍 언어
- **ccxt**: 암호화폐 거래소 API 통합
- **pandas**: 데이터 처리 및 분석
- **numpy**: 수치 계산
- **ta-lib**: 기술적 지표 계산
- **sqlite3**: 거래 기록 저장

### 4.2 설정 관리
- **YAML**: 설정 파일 형식
- **python-dotenv**: 환경 변수 관리
- **pydantic**: 설정 검증

### 4.3 모니터링 및 로깅
- **logging**: Python 표준 로깅
- **rich**: 콘솔 출력 개선
- **schedule**: 작업 스케줄링

## 5. 아키텍처 설계

### 5.1 모듈 구조
```
src/
├── core/
│   ├── __init__.py
│   ├── config.py          # 설정 관리
│   ├── logger.py          # 로깅 설정
│   └── database.py        # 데이터베이스 연결
├── strategies/
│   ├── __init__.py
│   ├── base_strategy.py   # 전략 기본 클래스
│   ├── supertrend.py      # 슈퍼트렌드 전략
│   └── rsi_mean_reversion.py  # RSI 평균회귀 전략
├── data/
│   ├── __init__.py
│   ├── market_data.py     # 시장 데이터 관리
│   └── indicators.py      # 기술적 지표 계산
├── trading/
│   ├── __init__.py
│   ├── portfolio.py       # 포트폴리오 관리
│   ├── risk_manager.py    # 리스크 관리
│   └── executor.py        # 거래 실행
└── main.py                # 메인 실행 파일
```

### 5.2 데이터 흐름
1. **데이터 수집**: 바이낸스 API에서 실시간 가격 데이터 수집
2. **지표 계산**: 기술적 지표 계산 (슈퍼트렌드, RSI)
3. **신호 생성**: 전략별 매매 신호 생성
4. **리스크 검증**: 포지션 크기 및 리스크 한도 확인
5. **거래 실행**: 검증된 신호에 따른 실제 거래 실행
6. **결과 기록**: 거래 결과를 데이터베이스에 저장
