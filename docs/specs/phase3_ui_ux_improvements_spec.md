# Phase 3: 구독 서비스 UI/UX 개선 명세서

## 1. 개요

2단계에서 완료된 Redux 상태 관리 아키텍처를 기반으로, 구독 관련 페이지(`SubscriptionPlans`, `SubscriptionManagement`)의 사용자 인터페이스(UI)와 사용자 경험(UX)을 대폭 개선한다. 사용자가 구독 상태를 명확히 인지하고, 직관적으로 서비스를 이용할 수 있도록 시각적 완성도와 상호작용성을 높이는 것을 목표로 한다.

## 2. 목표

- **직관성 강화**: 사용자가 각 구독 플랜의 장단점을 쉽게 비교하고, 현재 자신의 구독 상태를 명확하게 파악할 수 있도록 개선한다.
- **시각적 피드백 제공**: 데이터 로딩, 액션의 성공/실패 등 모든 상호작용에 대해 즉각적이고 명확한 시각적 피드백을 제공한다.
- **디자인 일관성 확보**: 프로젝트의 전체 디자인 시스템(`docs/design/web_design_guidelines.md`)에 부합하는 UI를 구현한다.
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 등 다양한 디바이스에서 최적의 사용자 경험을 제공한다.

## 3. 세부 작업 명세

### 3.1. `SubscriptionPlans.tsx` (구독 플랜 선택 페이지)

- **카드 디자인 도입**: 각 구독 플랜을 정보 카드 형태로 시각적으로 구분하여 표시한다.
- **추천 플랜 하이라이트**: 특정 플랜(예: 가장 인기 있는 플랜)에 "추천" 배지나 시각적 효과를 추가하여 사용자의 선택을 돕는다.
- **로딩 상태 개선**:
    - 초기 데이터 로딩 시, 텍스트 대신 **스켈레톤 로더(Skeleton Loader)**를 표시하여 사용자가 콘텐츠 구조를 미리 인지할 수 있도록 한다.
    - '구독하기' 버튼 클릭 시, 버튼 내부에 **스피너(Spinner)**를 표시하고 버튼을 비활성화하여 중복 클릭을 방지한다.
- **상호작용 개선**:
    - 플랜 카드에 마우스를 올리면(hover) 미묘한 그림자 효과나 크기 변화를 주어 상호작용성을 높인다.

### 3.2. `SubscriptionManagement.tsx` (구독 관리 페이지)

- **현재 구독 플랜 시각화**: 사용자가 현재 구독 중인 플랜을 다른 플랜들과 시각적으로 명확히 구분되는 별도의 컴포넌트로 표시한다.
- **액션 버튼 개선**:
    - '구독 취소', '플랜 변경' 등 주요 액션 버튼의 디자인과 문구를 명확하게 개선한다.
    - **구독 취소 시 확인 모달(Confirmation Modal)**을 추가하여 사용자의 실수를 방지한다.
- **상태 피드백 강화**:
    - 구독 취소, 재활성화, 변경 등 액션 성공 시, **토스트(Toast) 알림**으로 "구독이 취소되었습니다."와 같은 성공 메시지를 표시한다.
    - API 요청 실패 시, 사용자 친화적인 에러 메시지를 토스트 알림으로 표시한다. (예: "일시적인 오류가 발생했습니다. 다시 시도해주세요.")
    - 상태 변경 액션(취소, 재활성화 등)이 진행되는 동안 관련 버튼에 스피너를 표시하고 비활성화한다.

### 3.3. 공통 UI/UX 개선

- **알림 시스템(Notification System) 구현**:
    - 애플리케이션 전역에서 사용할 수 있는 토스트 알림 컴포넌트를 구현하거나, 기존 라이브러리(예: `react-hot-toast`)를 도입한다.
    - 성공, 실패, 정보 등 다양한 종류의 알림을 처리할 수 있어야 한다.
- **반응형 레이아웃 적용**:
    - CSS Grid 또는 Flexbox와 Media Query를 사용하여 화면 크기에 따라 플랜 카드 개수나 레이아웃이 유동적으로 변경되도록 구현한다.
    - 모바일 화면에서는 카드와 텍스트 크기를 적절히 조절하여 가독성을 확보한다.

## 4. 예상 결과물

- 개선된 `SubscriptionPlans.tsx` 및 `SubscriptionManagement.tsx` 파일
- 스켈레톤 로더, 모달, 토스트 알림 등 재사용 가능한 UI 컴포넌트
- 컴포넌트에 적용될 신규 CSS 또는 스타일링 코드
- (필요시) `package.json`에 추가된 UI 관련 라이브러리
