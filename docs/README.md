# 문서 인덱스

## 개요
이 디렉토리는 프로젝트의 모든 문서를 포함합니다.

## 디렉토리 구조

### 📁 `specs/` - 기능 명세서
- `phase1_minimal_trading.md` - Phase 1 최소 기능 명세서

### 📁 `team/` - 팀 협업 가이드
- `TEAM_STRUCTURE.md` - 팀 구조 및 역할 정의
- `COMMUNICATION_PROTOCOL.md` - 의사소통 프로토콜
- `SPEC_DRIVEN_WORKFLOW.md` - Spec Driven Development 워크플로우
- `TEAM_COLLABORATION_GUIDE.md` - 통합 팀 협업 가이드

#### 📁 `roles/` - 역할별 명세서
- `ARCHITECT_SPEC.md` - 시스템 아키텍트
- `STRATEGY_DEVELOPER_SPEC.md` - 전략 개발자
- `DATA_ENGINEER_SPEC.md` - 데이터 엔지니어
- `AI_ML_ENGINEER_SPEC.md` - AI/ML 엔지니어
- `DEVOPS_ENGINEER_SPEC.md` - DevOps 엔지니어
- `QA_ENGINEER_SPEC.md` - QA 엔지니어
- `PRODUCT_MANAGER_SPEC.md` - 프로덕트 매니저

#### 📁 `templates/` - 템플릿 모음
- `MEETING_TEMPLATES.md` - 회의 템플릿 (5가지 유형)
- `DOCUMENT_TEMPLATES.md` - 문서 템플릿 (5가지 유형)
- `CHECKLISTS.md` - 체크리스트 (8가지 영역)

### 📁 `human_manager/` - 인간 관리자 가이드
- `HUMAN_MANAGER_GUIDE.md` - 관리자 역할 및 서비스 가이드
- `SERVICE_IMPLEMENTATION_GUIDE.md` - 서비스 구현 상세 가이드
- `PRACTICAL_CHECKLISTS.md` - 실무 체크리스트 및 템플릿

## 주요 문서

### 시작하기
- `GETTING_STARTED.md` - 프로젝트 시작 가이드

### 개발 참여
- `team/TEAM_COLLABORATION_GUIDE.md` - 팀 협업 전체 가이드
- `team/SPEC_DRIVEN_WORKFLOW.md` - 개발 워크플로우

### 관리자 가이드
- `human_manager/HUMAN_MANAGER_GUIDE.md` - 관리자 기본 가이드
- `human_manager/SERVICE_IMPLEMENTATION_GUIDE.md` - 서비스 구현 가이드

## 사용 방법

1. **새로운 팀원**: `GETTING_STARTED.md` → `team/TEAM_STRUCTURE.md` → 해당 역할 명세서
2. **개발 참여**: `team/SPEC_DRIVEN_WORKFLOW.md` → `team/templates/` 활용
3. **관리자**: `human_manager/HUMAN_MANAGER_GUIDE.md` → `human_manager/PRACTICAL_CHECKLISTS.md`
4. **협업**: `team/COMMUNICATION_PROTOCOL.md` 참조
