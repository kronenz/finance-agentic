## 사용 방법

1. **새로운 팀원**: `GETTING_STARTED.md` → `team/TEAM_STRUCTURE.md` → 해당 역할 명세서
2. **개발 참여**: `team/SPEC_DRIVEN_WORKFLOW.md` → `team/templates/` 활용
3. **관리자**: `human_manager/HUMAN_MANAGER_GUIDE.md` → `human_manager/PRACTICAL_CHECKLISTS.md`
4. **협업**: `team/COMMUNICATION_PROTOCOL.md` 참조
