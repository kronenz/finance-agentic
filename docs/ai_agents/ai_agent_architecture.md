# AI 에이전트 아키텍처 문서

## 개요

AI 기반 적응형 암호화폐 거래 시스템은 다중 에이전트 아키텍처를 사용하여 시장 분석, 전략 선택, 리스크 관리, 거래 실행을 자율적으로 수행합니다.

## 에이전트 구성

### 1. 메타-컨트롤러 (Meta-Controller)
**역할**: 전체 시스템의 중앙 의사결정 및 조율
**위치**: `backend/app/ai/meta_controller.py`

**주요 기능**:
- 시장 국면 분석 결과 종합
- 전략 선택 및 전환 결정
- 리스크 관리 정책 적용
- 에이전트 간 통신 조율

**입력**:
- 시장 국면 분석 에이전트의 분석 결과
- 전략 분석 에이전트의 전략 추천
- 리스크 관리 에이전트의 리스크 평가

**출력**:
- 최종 거래 신호
- 전략 전환 명령
- 리스크 관리 조치

### 2. 시장 국면 분석 에이전트 (Market Regime Detector)
**역할**: 실시간 시장 국면 감지 및 분류
**위치**: `backend/app/ai/market_regime_detector.py`

**주요 기능**:
- HMM(Hidden Markov Model) 기반 시장 국면 분류
- ADX, Hurst Exponent 등 기술적 지표 분석
- 변동성 수준 평가
- 신뢰도 점수 계산

**분류되는 시장 국면**:
- `TREND_UP`: 상승 추세
- `TREND_DOWN`: 하락 추세
- `RANGE_HIGH_VOL`: 고변동성 횡보
- `RANGE_LOW_VOL`: 저변동성 횡보
- `CRASH_EVENT`: 급락 이벤트

### 3. VWAP 분석 에이전트 (VWAP Analyzer)
**역할**: 거래량 가중 평균 가격 분석
**위치**: `backend/app/ai/vwap_analyzer.py`

**주요 기능**:
- 실시간 VWAP 계산
- 표준편차 밴드 생성
- 가격 편차 분석
- 시장 참여자 평균 단가 추적

**분석 지표**:
- VWAP 값
- 1std, 2std, 3std 상하단 밴드
- 현재 가격과 VWAP 편차
- 거래량 가중치

### 4. 거래량 프로파일 분석 에이전트 (Volume Profile Analyzer)
**역할**: 거래량 프로파일 분석 및 시장 합의 영역 파악
**위치**: `backend/app/ai/volume_profile_analyzer.py`

**주요 기능**:
- POC (Point of Control) 계산
- VA (Value Area) 분석
- LVN (Low Volume Node) 식별
- 가격별 거래량 분포 분석

**핵심 지표**:
- POC: 최대 거래량이 발생한 가격
- VAH/VAL: Value Area 상단/하단
- LVN: 저거래량 구간

### 5. 리스크 관리 에이전트 (Risk Manager)
**역할**: 다층적 리스크 관리 및 모니터링
**위치**: `backend/app/ai/risk_manager.py`

**주요 기능**:
- 개별 포지션 리스크 평가
- 포트폴리오 리스크 분석
- 시스템 리스크 모니터링
- Kelly Criterion 기반 포지션 크기 조절

**리스크 레벨**:
- `INDIVIDUAL`: 개별 포지션 리스크
- `PORTFOLIO`: 포트폴리오 리스크
- `SYSTEM`: 시스템 전체 리스크

### 6. 강화학습 최적화 에이전트 (RL Optimizer)
**역할**: 전략 파라미터 최적화 및 학습
**위치**: `backend/app/ai/rl_optimizer.py`

**주요 기능**:
- PPO 알고리즘 기반 학습
- 다중 목표 최적화 (수익률, 샤프 지수, 최대 낙폭)
- 환경 상태 및 행동 공간 정의
- 보상 함수 설계

**학습 환경**:
- 상태 공간: 시장 데이터, 기술적 지표, 포지션 정보
- 행동 공간: 매수/매도/보유, 포지션 크기
- 보상 함수: 위험 조정 수익률

### 7. 유전 알고리즘 진화 에이전트 (Genetic Algorithm)
**역할**: 전략 규칙 진화 및 최적화
**위치**: `backend/app/ai/genetic_algorithm.py`

**주요 기능**:
- 트리 구조 기반 규칙 표현
- 교배, 돌연변이, 선택 연산자
- 백테스팅 기반 적합도 평가
- 전략 규칙 진화

**진화 과정**:
1. 초기 개체군 생성
2. 적합도 평가 (백테스팅)
3. 선택, 교배, 돌연변이
4. 새로운 세대 생성
5. 수렴 조건 확인

## 에이전트 간 통신

### 통신 프로토콜
- **RESTful API**: 동기적 명령 및 상태 조회
- **WebSocket**: 실시간 데이터 스트리밍
- **Message Queue**: 비동기 통신 (RabbitMQ/Kafka)

### 데이터 흐름
```
시장 데이터 → 시장 국면 분석 → 메타-컨트롤러
                ↓
VWAP/거래량 프로파일 분석 → 메타-컨트롤러
                ↓
리스크 관리 → 메타-컨트롤러 → 거래 신호 생성
                ↓
강화학습/유전알고리즘 → 전략 최적화
```

## 성능 지표

### 응답 시간
- 시장 국면 분석: < 100ms
- VWAP 계산: < 50ms
- 거래량 프로파일 분석: < 200ms
- 리스크 평가: < 50ms

### 정확도
- 시장 국면 분류 정확도: > 80%
- VWAP 예측 정확도: > 85%
- 리스크 예측 정확도: > 90%
